# LPU Scholarship Assistant

Open index.html in a browser. Keep styles.css and script.js in the same folder.

Enter your name, CGPA, annual family income and achievement category. Save your details to check the sample rules. Search scholarships, filter matches, save entries and track application statuses.

All amounts are INR. The entries use sample rules and amounts, not official LPU offers. Reference: https://www.lpu.in/scholarship/scholarship.php

The project uses semantic HTML, external CSS, Grid, media queries, JavaScript arrays and objects, functions, conditions, event listeners, DOM updates and localStorage. Your data stays in this browser. No applications are sent to LPU.

This simplified version has one page with a profile form, scholarship list, application tracker and short instructions.
